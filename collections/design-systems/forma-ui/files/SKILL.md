# Forma UI

Lire DESIGN.md et tokens.css, puis components.css et prototype.html pour les comportements. Utiliser le référentiel Design Studio à la racine du dépôt lorsqu'il est disponible.

Préserver les contraintes produit. Choisir les surfaces adaptées au besoin ; ne pas transformer un site public en dashboard. Garder la grille, l'index, la hiérarchie des titres, la signalétique bleue, les surfaces planes. Ne pas copier les données fictives. Respecter les tokens, labels natifs, focus, responsive et reduced motion. Charger les skills Agent Commons adaptés sans installation automatique. Construire, tester, corriger, puis valider avec captures réelles. Indiquer les vérifications non exécutées. Ne pas inventer de métriques ni de conformité.
