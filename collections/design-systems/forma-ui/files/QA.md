# Recette initiale

Sources méthodologiques consultées : Agent Commons UPE, UX Psychology, frontend-design, Hallmark (plancher), Impeccable (craft floor), frontend-a11y et design-system (architecture tokens). Les scripts externes et workflows complets des skills n'ont pas été exécutés ; seuls leurs principes pertinents ont été adaptés. Pas d'installation de skill.

Contrôles effectués sur les blobs : CSS inline matches sources; JS syntax; initial; accent normalization; combined empty; category; reset; empty search; text contrast pairs. Contrastes calculés (couples opaques) : #171a1d / #f3f4ef = 15.81:1, #4a555e / #f3f4ef = 6.90:1, #1937a5 / #ffffff = 9.85:1, #1937a5 / #f3f4ef = 8.91:1. La simulation n'est pas un test navigateur. Les contrôles de rendu Chromium, clavier réel, zoom, lecteurs d'écran, performance et la revue indépendante restent à effectuer. Le thème ne porte pas de certification WCAG.
